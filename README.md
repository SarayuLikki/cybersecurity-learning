# Purple Team Cybersecurity Project

### Attacker Simulation, Apache Log Analysis and Firewall Rule Verification

**Student:** Sarayu
**Project Type:** Purple Team Cybersecurity
**Operating System:** Kali Linux and Windows 11

## Project Overview

This project demonstrates a practical Purple Team cybersecurity exercise involving both attacker and defender roles.

The attacker role focuses on reconnaissance, service discovery, directory enumeration and web-server assessment.

The defender role focuses on Apache access-log monitoring, suspicious activity detection, IP correlation and firewall rule verification.

## Roles Performed

**Red Team – Attacker**

* Network reconnaissance using Nmap.
* Directory enumeration using Gobuster.
* Web-server assessment using Nikto.
* HTTP request simulation.

**Blue Team – Defender**

* Apache access-log monitoring.
* Suspicious request identification.
* Attacker IP correlation.
* Firewall rule implementation and verification.
* Legitimate client traffic validation.
